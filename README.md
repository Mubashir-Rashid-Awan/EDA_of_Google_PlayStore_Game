#  Google Play Store Games - Exploratory Data Analysis (EDA)

##  Description

This project focuses on performing Exploratory Data Analysis (EDA) on Google Play Store Games data using Python. The goal of this analysis is to explore trends, patterns, and relationships among different game attributes such as ratings, downloads, genres, developers, pricing models, and content ratings.

Through data cleaning, visualization, and statistical exploration, this project uncovers valuable insights into the mobile gaming ecosystem and highlights factors that may influence game popularity on the Google Play Store.

---

##  Features

- Data Loading and Exploration
- Data Cleaning and Preprocessing
- Missing Value Analysis
- Duplicate Record Handling
- Top 10 Most Downloaded Games Analysis
- Genre Distribution Analysis
- Rating vs Downloads Analysis
- Free vs Paid Games Comparison
- Top Developers Analysis
- Content Rating Distribution Analysis
- Insight Generation through Visualizations
- Exploratory Data Analysis using Python

##  How to Run This Project on Windows

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
```

### 2. Navigate to the Project Directory

```bash
cd YOUR_REPOSITORY_NAME
```

### 3. Install Required Libraries

```bash
pip install pandas numpy matplotlib jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

### 5. Open the Notebook

Open:

```text
EDA-of-Google-Playstore-Games.ipynb
```

and run all cells.

##  Key Insights

- Free-to-play games dominate the Google Play Store.
- Sports and Action are among the most popular genres.
- Most games maintain ratings above 4.0.
- Highly rated games generally attract more downloads.
- The majority of games target the "Everyone" audience category.
- Well-established developers have a strong presence in the marketplace.
